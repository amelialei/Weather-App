# Weather-App

## Overview
This project is a web-based weather application built using Django and Bootstrap. The app fetches and displays the current weather and a forecast for the user's location based on their IP address. It provides key weather data, including temperature, humidity, wind speed, pressure, and sunrise/sunset times for the current and next day.

## Features
- Fetches weather data based on the user's IP address using the Weather API.
- Displays:
  - Current weather: temperature, humidity, wind speed, feels like temperature, pressure, and a weather icon.
  - Forecast for the next day: average temperature, humidity, wind speed, sunrise, sunset, and a weather icon.
- Responsive layout using Bootstrap.
- Displays location-based data automatically using the user's IP.

## Technologies Used
- Frontend:
  - HTML
  - CSS (with Bootstrap 5.3.3)
  - JavaScript
    
- Backend:
  - Python (Django Framework)
  - WeatherAPI for weather data
  - ipifyAPI for location data based on the user's IP
